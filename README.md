# DarkSpot
DarkSpot помогает food-бизнесу находить лучшие места для запуска dark kitchen с помощью парсинга, открытых данных и геоаналитики.
# Наша команда
Сайгак Андрей (@lilDronny), Хайретдинов Эльдар (@Lolotop12)
# Идея компании
DarkSpot — это data-driven платформа для запуска dark kitchens в лучших локациях города. Сервис анализирует конкурентов, аренду, транспортную доступность, плотность населения и сигналы локального спроса, чтобы находить районы с максимальным потенциалом для delivery-first бизнеса. DarkSpot снижает риск неудачного открытия и помогает принимать решения о запуске точек на основе данных, а не интуиции.
